# MN5813 – Basketball Performance Analysis

## Project Overview
This project analyses professional basketball player performance using multiple datasets. The aim is to explore player contributions, seasonal trends, and award distribution through data cleaning, analysis, and visualisation.

## Dataset
The following datasets were used:
- basketball_master.csv – Player demographic information
- basketball_awards_players.csv – Player awards history
- basketball_player_allstar.csv – Seasonal performance statistics
- basketball_teams.csv – Team information

All datasets are publicly available and loaded directly from this repository.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and preprocessing
- Merging datasets using player identifiers
- Season-wise performance analysis
- Top 5 player analysis
- Award distribution analysis
- Data visualisation (bar charts, line charts, stacked charts)

## Key Insights
- Player performance is highly concentrated among a small group of elite players.
- Seasonal trends show gradual changes in performance metrics.
- Award distribution strongly correlates with high performance levels.
